Executive Mission & Purpose

AppService is an enterprise-grade administration and service framework developed by Bahman Heydari Nejad. It marries the robust backend stability, dependency injection, transaction management, and security ecosystem of Spring Boot (2.1.4.RELEASE) with the high-productivity, component-driven UI capabilities of JavaServer Faces (JSF 2.3 / Mojarra), PrimeFaces, and the AdminFaces (AdminLTE 2) theme library.

🧩

Dynamic Panel-Driven Architecture

Instead of traditional multipage reloads, AppService implements a single-dashboard dynamic view architecture (dashboard.xhtml). UI panels are first-class entities stored in the relational database, authorized via dynamic Role-Based Access Control (RBAC), and injected dynamically at runtime via panelHandler.activePanel.resourceLocation without requiring full browser refreshes.

⚡

Flexible Multi-Identifier Authentication

Users can authenticate via a unified login input that intelligently disambiguates between Email address (RFC regex match), Mobile phone number (E.164/national pattern), or standard Account name, protected by BCrypt password encryption, HTTP session concurrency control, and asynchronous transactional mail delivery.

💡 Architectural Observation
AppService is designed as an extensible enterprise template. It combines clean layered abstraction (Entities → Repositories → Services → View/Crud Beans → XHTML Components) with dynamic metadata persistence, enabling administrators to configure menus, UI panels, permissions, and roles directly from the database without rebuilding or redeploying the application.

🔒 Authentication, Security & Session Management

Core identity verification, custom Spring Security provider, session tracking, and granular authorization barriers.

Multi-Identifier Login

Security

Unified authentication input that dynamically analyzes credentials. Users can sign in using their Account Name, RFC-compliant Email address, or E.164 Mobile Phone number.

Handler:AccountService.loginByAny()
Regex Beans:emailPattern, mobilePattern
UI Component:modal_signin.xhtml & index.xhtml

Spring Security Provider

Core

Implements Spring's AuthenticationProvider directly inside AccountService, constructing UsernamePasswordAuthenticationToken with authorities mapped from roles.

Component:ir.appservice.model.service.AccountService
Encryption:BCryptPasswordEncoder (10 rounds)
Context:SecurityContextHolder synchronization

Session Concurrency & Registry

Security

Enforces session concurrency policies via Spring's SessionRegistryImpl and HttpSessionEventPublisher, tracking active principals and redirecting expired sessions.

Max Sessions:100 concurrent sessions configured
Expired URL:/index
Session Bean:SessionBean.showSessions()

Dynamic Panel RBAC

Authorization

Granular Role-Based Access Control checking whether an authenticated account is permitted to load a specific Panel or invoke an entity action before display.

Method:AccountService.isAuthorized(Account, BaseEntity)
Enforcement:Intercepted inside PanelHandler.openPanel()
Fallout:Emits Access Denied growl and resets to default

Anonymous User Redirection

View Guard

Pre-render view lifecycle hook in JSF (preRenderView event) that inspects authentication status and forces unauthenticated users to the index signin page.

Event:<f:event type="preRenderView">
Listener:SessionBean.redirectAnonymousUsers()
Protected:dashboard.xhtml

Session Inspector Modal

Diagnostic

Live session diagnostic modal launched from the top navigation bar (SESSION_INFO_DIALOG) enabling operators to view active session attributes and client data.

Dialog File:/elements/session_info.xhtml
Trigger:fa fa-laptop button in top navbar
Data:Session ID, creation time, client user-agent

✉️ Communication & Password Recovery

Asynchronous email sending, cryptographic password reset tokens, and outbox auditing.

Asynchronous Mail Engine

Async Mail

Non-blocking email dispatch service utilizing Spring's @Async and JavaMailSender, constructing MIME messages with HTML body and attachment support.

Service:ir.appservice.model.service.EMailService
Method:@Async sendMail(Email email)
Protocol:SMTP with TLS (smtp.gmail.com:587)

Multi-Attachment Emails

MIME

Seamless email attachment handling by converting relational Document records into Spring ByteArrayResource streams via MimeMessageHelper.

Recipients:Comma-separated To, CC, and BCC lists
Attachments:List<Document> attachments
Timestamp:Updates sentDate automatically upon delivery

Tokenized Password Reset

Recovery

Secure password recovery process: generates 64-character random alphanumeric tokens, dispatches an HTML notification email with an embedded link, and validates token existence.

Entity:ResetPasswordToken (64-char token)
Generator:RandomStringUtils.randomAlphabetic(64)
Service:ResetPasswordTokenService.resetPassword()

Password Reset View & REST

Endpoint

Dedicated reset interface (resetPassword.xhtml) and Spring MVC controller (ResetPasswordController) parsing incoming query tokens and executing updates.

URL:/resetPassword?token={token}
Controller:GET /resetPassword/{resetPasswordToken}
Bean:ResetPasswordBean with BCrypt encoding

🌐 HTTP & REST Endpoint Reference
