AppService Enterprise Platform

Modular Hexagonal Backend & AdminLTE Portal

A high-performance enterprise service pairing Spring Boot, Spring Security, Spring Data JPA, and AdminFaces (JSF 2.3 + PrimeFaces + AdminLTE). Provides dynamic role-based access control, runtime panel & menu dispatching, binary document streaming, generic CRUD automation, and an automated XML bootstrap feeder.

Dynamic Panels

Menus and panels are managed as JPA database entities, enabling instant menu reordering and layout reconfiguration without application redeployment.

Concurrent Sessions

SessionRegistry enforced up to 100 concurrent sessions with Spring Security custom auth provider and BCrypt password encryption.

Binary Streaming

High-throughput document storage with zero-cache HTTP streaming endpoints (/document/{id}) for avatars, PDFs, and data sheets.

Automated Feeder

Bootstrap loader (feeder.xml) pre-seeds administrative accounts, root roles, icons, and menus upon cold boot.

Hexagonal & Layered System Architecture

Architectural Separation: AppService enforces a clean separation between Web Presentation (JSF/AdminFaces Beans), RESTful Gateways, Business Services, and JPA Repositories. Entities extend a centralized BaseEntity providing auto-generated IDs, timestamps, and optimistic locking.

Dynamic RBAC & Session Management Engine

Granular Account Model

Account models authentication credentials (email, mobile number, BCrypt password), connected NaturalPerson metadata, profile avatars, and a set of assigned Roles.

Dynamic Permission Binding

Roles link directly to permitted Panels and Menu items. Granting or revoking access updates immediately without needing to invalidate active user sessions.

Session Registry Protection

Configured with maxSessions(100) and maxSessionsPreventsLogin(false). If an account expires, the user is safely redirected to the login bar.

Dynamic Menu & Panel Presentation Engine

Unlike hardcoded web applications, AppService renders its dashboard using database-driven UI entities. The PanelHandler bean maintains the active view state and dynamically loads XHTML facelets via JSF <ui:include src="#{panelHandler.activePanel.resourceLocation}">.

Menu Hierarchy & Priority Ordering

Menus support icon classes (Glyphicons & FontAwesome), priorities (0 to 100), and types (PANEL_MENU, URL_MENU). The sidebar renders items sorted by weight.

AdminLTE Component Integration

Styled with AdminLTE box-success box-solid panels, animated toggle speeds, expandable control sidebars, and native mobile responsive navigation trees.

Generic CRUD Automation & Lazy Data Grids

BaseCrudBean Architecture

Generic abstraction handling standard entity lifecycles: save(), update(), delete(), find(), and validation error propagation to PrimeFaces Growl.

PrimeFaces AppLazyDataModel

Server-side pagination and dynamic filtering. Handles datasets with millions of rows without loading all records into memory.

Declarative AppUIColumn

Programmatic table column definitions supporting sorting, custom filters, formatters, and localized column headers.

Binary Document Management & Streaming Service

Streaming Controller Endpoint
GET http://localhost:8001/document/{id}
Cache-Control: No-Store Headers

Enforces response.setHeader("Cache-Control", "no-store") and Pragma: no-cache to prevent sensitive documents and avatars from being retained in untrusted intermediary proxies.

JSF DocumentStreamer Bean

Integrates with PrimeFaces <p:graphicImage value="#{documentStreamer.image}"> for instant avatar and thumbnail rendering across administrative dialogs.

Mail Gateway & Password Recovery Flow

One-Time Recovery Tokens

When a user requests a password reset from the index sidebar, a unique ResetPasswordToken is minted and recorded with a timestamp.

Spring Mail Integration

Asynchronously dispatches formatted email notifications via Gmail SMTP TLS with customizable subject lines and tokenized deep links.

Password Regex Validation

Enforces strict password regular expressions (regx.password=^([a-z]+[A-Z]+[0-9]+){8,}$) requiring uppercase, lowercase, numbers, and minimum length.
